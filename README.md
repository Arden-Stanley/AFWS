# Autonomous Ground Vehicle for Precision Weed Detection and Targeted Pesticide Spraying Using Deep Learning

## Abstract:
Efficient and targeted weed management remains a significant challenge in modern agriculture, as conventional blanket pesticide application increases chemical consumption, operational cost, and environmental impact. This paper presents an autonomous ground vehicle for precision weed control that integrates perception, navigation, and actuation within a single platform. The system employs a Light Detection and Ranging (LiDAR) sensor for autonomous navigation across uneven agricultural terrain. Simultaneously, a real-time weed detection and classification pipeline is implemented using the YOLO (You Only Look Once) deep learning framework integrated with a camera-based vision system. The proposed framework continuously captures field imagery along an autonomously generated navigation path and performs real-time object detection to identify and classify weed species. Detected weeds are spatially localized with high inference speed and evaluated using standard performance metrics, including mean Average Precision (mAP) and Intersection over Union (IoU). Based on the classification output, control commands are generated to actuate a localized pesticide spraying mechanism, ensuring chemical application is restricted exclusively to detected weed regions. Experimentalresults demonstrate the feasibility of  combining deep learningbased object detection with autonomous agricultural vehicles for accurate and scalable precision spraying. The proposed system reduces unnecessary pesticide usage and off-target spraying, contributing to more sustainable and environmentally responsible weed management practices.
